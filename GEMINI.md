# GEMINI.md

## Project Overview
This repository is a personal research workspace dedicated to high-quality, factual documentation on various topics, including finance, travel, and utility services. It is a **non-code project**; there is no build system, test suite, or runtime. The primary deliverables are Markdown and plain text files designed for personal reference and planning.

## Key Files
- **`cell-service-research.md`**: Comprehensive comparison of mobile plans (Visible, T-Mobile, Verizon, etc.) for 2026, including budget and premium tiers.
- **`hysa-research-2026.md`**: Detailed analysis of High-Yield Savings Accounts (HYSA) rates, pros/cons, and recommendations based on the 2026 rate environment.
- **`indianapolis_destinations.md`**: A structured guide to parks, historical sites, and museums within 50 miles of Indianapolis.
- **`payment-gateways-sole-proprietor-llc.md`**: Research on payment processors suitable for sole proprietors and LLCs.
- **`military_tax_prep_research.txt`**: Plain text notes regarding tax preparation resources for military members.
- **`CLAUDE.md` / `AGENTS.md`**: Foundational instructions for AI assistants, outlining file naming and prose style conventions.

## Usage & Conventions
This repository follows specific standards to ensure clarity and consistency across all research documents.

### File Naming
- **Format**: Lowercase with hyphens (e.g., `topic-name-2026.md`).
- **Topic-First**: Lead with the primary subject matter.
- **No Spaces**: Avoid spaces or special characters in filenames.
- **Root-Level**: New files should be placed in the repository root unless a topic becomes large enough to warrant a sub-folder.

### Prose Style & Formatting
- **Conciseness**: Use short paragraphs, descriptive headings, and compact bullet lists.
- **Factual**: Maintain a source-backed, objective tone. Remove all draft placeholders or "TODO" notes before committing.
- **Markdown Tables**: Use tables for side-by-side comparisons of rates, prices, or features.
- **References**: Include a "Research via..." or "Verify current pricing..." footer with the date of the research.

### Quality Control
Since there is no automated testing, all verification is manual:
1. Verify that Markdown headings render correctly.
2. Check all links, dates, and quoted figures for accuracy.
3. Ensure the filename strictly follows the `lowercase-with-hyphens.md` convention.
4. Remove redundant or duplicate sections.

### Commits
Use concise, imperative commit messages (e.g., `Add payment gateway comparison`, `Revise Indianapolis destinations notes`).
